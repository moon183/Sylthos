# 演讲助手 API 配置与使用

已实现真实 HTTP 调用代码。分发默认开关关闭、密钥为空；开发验收使用虚构凭据和本机模拟服务。2026-10-25 用户填写配置后，已通过官方 DeepSeek 接口的最小连接测试，未发送 PPT 或彩排数据；这不代表长文计划已通过真实接口验收。

## 填写入口

启动当前源码，进入“演讲材料”或“彩排统计”，在 AI 卡片点击“API 设置”。

1. 勾选“启用在线演讲助手”。
2. 接口地址默认 `https://api.deepseek.com`；也可填写兼容服务的 `/v1` 基地址或完整 `/chat/completions` 地址。程序会处理路径，避免重复拼接。
3. 模型默认 `deepseek-flash`，可以改成账户支持的其他模型。
4. API Key 填自己的密钥，点击“保存设置”。
5. 点击“测试连接”。该操作仅发送“请只回复 OK”，不发送 PPT 或彩排数据。测试会临时关闭 DeepSeek 思考模式，生成任务仍遵循用户保存的模式设置。

默认地址、当前模型名和请求协议依据 [DeepSeek 首次调用文档](https://api-docs.deepseek.com/zh-cn/)、[Chat Completions 文档](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)核对。

也可直接编辑项目根目录 `assistant_api.local.json`，参考无密钥的 `assistant_api.example.json`：

```json
{
  "enabled": true,
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-flash",
  "api_key": "在本机填写自己的密钥",
  "timeout_s": 120,
  "max_tokens": null,
  "json_mode": true,
  "thinking": false
}
```

本机文件已列入 Git 忽略。它以明文保存凭据，勿作为演示材料或分发包复制给其他人；真实密钥不需要发送到聊天里。程序的现有 `config.json` 不改写。应用每次开始请求时重新读取本机文件，修改后不必重启。

### 最大输出额度

“最大输出 tokens”留空（JSON 中为 `null`）时，程序省略 `max_tokens`，由服务端按模型和模式采用默认额度。也可填写正整数；它限制单次请求的输出，思考模式的推理内容也占用额度，并非整份 PPT 的总字数。长 PPT 的不同批次分别使用该额度。

截至 2026-10-25，当前 DeepSeek Flash / V4 Pro 支持最大 393216 tokens（384K）；程序按已知模型校验，兼容服务的其他模型上限由服务端判断。官方省略参数时，非思考模式默认8K、思考模式默认64K，最高推理强度默认128K，详见 [接口参数说明](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)。开启思考模式可先显式填写65536，长文需要时再提高；设置最大额度不保证每次都会生成相同长度。

参数不合法时会显示具体字段错误，JSON 语法错误会显示行列位置。单个参数错误不会在设置窗口清空已填密钥。升级本次源码需重启程序；之后仅改配置文件则无需重启。

### 长文生成与等待

请求过程中会分别显示当前批次和已等待秒数，不用估算百分比。等待30秒后会提示长文或思考模式可能需要较长时间；完成、失败或取消后停止计时。取消仅停止等待并废弃迟到结果，已经发送到服务端的请求不保证撤回。

新配置默认网络超时120秒，可在“API 设置”调整为5—600秒。已有文件的超时原值保持不变，原来填写30秒的用户可根据需要手动调高。这个值限制单次网络等待，不是整份PPT所有批次的总时限。超时后显示具体秒数和调整入口，不会因超时自动再次生成。

## 生成演讲计划

1. 导入并保存材料版本，核对正文、备注和补充。
2. 填写受众、目标时长和演讲重点。
3. 点击“生成演讲计划”，查看整体思路、逐页重点、建议讲稿、过渡语、可能的问题和待核实事项。
4. 点击“采用并保存计划”，生成绑定当前材料版本的独立计划。生成预览和失败请求不会覆盖原计划。
5. 在彩排统计选择这个计划，再开始彩排。可导出 AI 计划为 Markdown。

长文稿按批次发送，每批最多6页并携带全篇标题提纲；预算在全部批次成功后统一计算，总和等于目标秒数。隐藏页保留页码、不分配时间。当前上限为60个非隐藏页、总计60000字符；单页或全篇提纲过长时明确停止，不静默截断。

已保存 AI 计划可以重新载入；“另存当前计划”保留逐页建议，改总时长时调整预算，未改时预算保持不变。手工调整会在来源元数据中标记，不会冒充重新生成。

### 逐页编辑和复用讲稿

1. AI生成后先点击“采用并保存计划”；也可选择已有计划，或从新建草稿手工编写。
2. 在“逐页演讲稿”中切换页面，修改重点（每行一条）、讲稿和过渡语。这里的页码与上方PPT核对区同步；可能的问题和待核实事项继续保留。
3. 回到“演讲计划草稿”卡片，点击“另存当前计划”或“保存计划草稿”。修改将保存为独立计划，旧计划及历史彩排的引用不改变。已有预算在总时长不变时保持原样，改变总时长时按原比例重新分配。
4. 点击“导出已保存讲稿”，得到本机Markdown文件；未保存修改时须先保存。导出会区分AI生成、AI生成后人工调整和手工编写。没有预算的手工草稿不会被误称为隐藏页。
5. 在彩排统计页选择这个新计划开始练习。逐页编辑和导出不调用API，也不需要再次生成。

切换计划或材料时沿用未保存确认。若同时修改材料和讲稿，保存新材料版本之前会提示当前未保存讲稿将被清空；拒绝时输入保持原样。计划保存失败也保留工作副本。

## 分析彩排统计

结束彩排或选择历史记录后，点击“分析本次彩排”。程序先计算总时长、逐页实际/预算/差值、分发和拒绝计数，再让模型提出最多3项练习建议。模型需引用已存在的事实编号，界面和导出中的证据文字由程序提供。

材料和计划按该场次绑定的版本读取；未关联材料仍可分析基本统计，绑定文件缺失时会标明依据不足。当前没有语音转写与页码对齐数据，因此复盘不能据此确认漏讲、口头禅、情绪或手势识别准确率。AI 建议应结合原始统计核对。

## 发送范围与错误处理

- 连接测试：只有测试文本。
- 计划：选中材料的逐页正文、备注、补充、标题提纲及用户目标。
- 复盘：选中场次的统计、程序计算的事实、绑定材料文字和演讲重点。
- 不上传原 PPTX、图片、音频或摄像头画面。
- 网络超时、鉴权、余额、限流、接口路径错误、非 JSON 或截断结果会显示错误。429/部分5xx最多重试一次，不无限请求。
- 取消会停止后续批次并阻止迟到结果进入界面或保存；已经发送到服务端的请求不保证撤回。关闭窗口同样会废弃结果。
- 错误提示不展示服务端原始错误正文，避免密钥或材料被带入日志。重定向不会携带 Authorization 自动跟随。
- 兼容服务不支持 JSON 输出参数时可取消“使用 JSON 输出模式”，但模型正文仍需返回指定 JSON 结构。
