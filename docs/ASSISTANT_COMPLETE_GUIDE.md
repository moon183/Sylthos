# 演讲助手完整使用说明

本次完成前面方案中的准备、练习、改进闭环及后续文字答辩、内容复盘功能。核心手势控制仍走既有离线管线。

## 启动与资料

最终独立程序目录为 `dist/assistant_complete_checked/GesturePPT/`，启动其中的 `GesturePPT.exe`。移动时复制整个目录，包括 `_internal` 和 `models`，不能只复制exe。原 `dist/GesturePPT` 与源码中的个人配置、材料和历史均保留。

独立包是脱敏配置，语音默认关闭，不附带真实API密钥、私人日志或个人手势样本。首次请在“API设置”自行配置；如需立即沿用原密钥与历史，可继续在源码目录运行 `.venv\Scripts\python.exe -X utf8 -m src.main`。

## 准备演讲

1. “演讲材料”导入并保存PPTX版本，核对原文、备注，补充图片/图表说明。
2. 填受众、重点、目标分钟，点击生成；核对后“采用并保存计划”。
3. “逐页演讲稿”编辑重点、讲稿、过渡语和本页预算秒数；0表示未分配，隐藏页不分配。总和、目标与差值即时显示。
4. 可按比例或平均分配至非隐藏页；改变总目标也即时重分配。手工小数秒预算会原样保存，总和不符则拒绝保存且保留输入。全空预算仍可保存为草稿。
5. 另存为新计划并导出讲稿；旧计划及旧彩排仍引用原版本。

## 彩排、内容与提醒

1. 打开实际PowerPoint，确认与所选材料版本一致；开启原有手势监控。
2. 在“彩排统计”选择材料/计划。需要内容复盘时，先到“语音识别”手动开启识别，再明确勾选“收录本次彩排最终转写”，然后开始彩排。
3. 本地提醒显示总目标剩余/超出，以及当前页可观测累计预算剩余/超出；未知页暂停逐页判断，不会自动联网或开麦。
4. 结束后可看逐次进入/离开页时间线、回访、未知区间和最终转写。对齐使用采集时间，跨页语段关联多页，未知区间保持不确定。开启收录前的片段不事后补入，上一场迟到结果不会写入新场。
5. 点击“分析本次彩排”看基于统计事实的建议；点击“分析讲述内容”看重点覆盖、重复和过渡建议，后者必须引用可核实原句及页码。没有最终转写则拒绝内容分析，不伪造漏讲。

采集丢帧、队列积压、停止时尚未定稿或识别失败可能造成缺失。ASR可能漏识/误识；没有匹配原句不等于实际没讲。内容分析不评价音调、真实准确率或观众情绪。

## 练习任务与对比

- 在统计复盘点击“保存为练习任务”，或在问答中明确采用待确认练习；每轮最多三项优先任务。
- “练习与比较”可手工创建任务、设页码和目标秒数、查看最新对应页耗时/计划预算，复查后标完成或恢复。重复采用同一完整来源不会重复创建，也不会清除完成状态。
- 选择同一材料版本的两场彩排比较与导出。未知页不当作0，目标变化有提示，用时减少不直接声称质量提高。修改过版本的PPT不按相同页码硬比。

## 工具追问与文字模拟答辩

在“演讲问答”选择固定材料/计划及允许读取的历史，输入后点击发送：

- 工具追问可读取提纲、指定页面、计划、选中场次，比较两场并提出待采用任务。
- 模拟答辩先提问，再填写回答，助手引用材料和回答原句评价、追问；可在已有回答后直接总结，输入框清空也可总结。
- 历史问答在本机保存，可重新查看和导出；保存失败会保留明确提示和结果，仍可导出。
- 不变的范围刷新不会丢会话；真正切换材料、计划或允许读取的历史会使旧请求失效。

工具不能读取任意文件、执行命令或访问其他网址。每轮最多5次模型请求、8次工具调用；工具参数4096字符，单次输入8000字符，固定上下文120000字符、对话180000字符、最多30轮。讲述复盘最多1000个转写段、120000字符输入、30项有引用发现。超限明确拒绝，不静默丢内容。

## 联网与取消

只有显式点击测试、生成、分析、发送才请求配置的接口。发送所选范围的文字/统计/问答/最终转写，不向演讲助手上传音频、图像或PPTX。取消停止后续流程并废弃迟到结果；服务端已接到的请求不保证撤回。

新配置超时默认120秒，可设5—600秒，旧配置不覆盖。请求显示已等待时间；超时不自动重复生成。输出额度可手工设置或使用模型默认，具体供应商限制见原API配置说明。

## 验收与人工操作

软件自动验收包括单元/GUI回归、使用虚构密钥的本机真实HTTP完整流程、模拟深浅主题、独立审查以及独立包启动。真人麦克风/PPT页码采样、真实模型长流程质量和无Python干净电脑仍需实际设备验证。

建议人工跑一次：固定PPT与计划→开始监控/语音并选择收录→跨页讲述/短暂断开页码→结束→核对转写原句和页关联→复盘采用任务→再练一次→比较并复查任务→文字答辩及总结。语音采集和模型效果不能用合成测试替代。
