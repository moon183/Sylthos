# C4 显示适配检查 — 2026-10-23

本轮只读检查，未修改项目源码或用户配置。

## 范围

Windows 原生 Qt，使用 QT_SCALE_FACTOR 分别注入 1、1.25、1.5、2，未改 Windows 系统设置。分别检查 1165×720、960×600、1440×900 三种逻辑窗口尺寸、导航展开/收起、九个页面，共216个布局场景。截图等待页面切换动画结束；另有深色预览对照。使用合成色块代替摄像头帧，不采集真人图像。

不是四台物理显示器实测，未验证跨显示器移动和硬件刷新率差异。小窗口新问题不在既有测试的覆盖范围内。

## 已确认问题

1. 960×600预览页：展开导航后摄像头横向范围16..691，侧栏529..779，两者重叠162逻辑像素。侧栏高度被压缩至520，原定高卡片和按钮也发生挤压；收起导航同样存在横向重叠。
2. 960×600自定义手势页：448×252固定轨迹预览与92×48按钮无法容纳在缩小的确认卡片内，按钮叠到预览上，尚未录制文字挤成竖排，训练说明被截断。截图c4-1-960-custom_gesture.png。
3. 高缩放下初始窗口不完整处于可用屏幕内。200%运行时可用区域1280×696，默认启动外框测得(320,93,1157,716)，右侧与底部超出；需同时检查初始大小和位置。

## 可接受现象与保持项

1165×720基线和1440×900下检查的主要页面没有上述重叠。语音与设置页在小窗口通过纵向滚动承载内容。主题页在960×600出现8/125逻辑像素横向滚动（导航收起/展开），内容仍可访问，优先级低于遮挡问题。保持已有主题、字体、灰色说明、标准窗口布局及导航动效。

## 验证

150%下原生Qt摄像头预览/浮层/彩排动画/灰字与色号相关47项测试通过。测试覆盖既有行为，不意味着新发现的小窗口问题通过。

## 建议修复范围

仅当可用空间不足时启用紧凑布局：预览按比例缩小画面并保障侧栏内容可访问；自定义手势必要时改为上下排列，保留样本列表滚动；初始窗口依据当前屏幕可用区域确定尺寸与位置。标准1165×720布局保持不变。C4暂未判定通过，需修复后再进行人工观感验收。
