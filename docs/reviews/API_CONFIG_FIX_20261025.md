# API 配置读取与输出额度修复（2026-10-25）

## 原因与修复

用户点击连接测试后，界面将 max_tokens 校验失败误报为 JSON 无法读取。原值10000000000超过当前模型实际输出上限，原程序128—32768的校验范围也过于保守。

- JSON 语法错误显示行列位置；字段校验错误保留具体、安全的提示。
- 设置窗口可载入其余有效字段供编辑，单个参数无效时保留已填密钥；保存仍进行严格校验。
- 最大输出输入支持留空/null，由服务端按模型与模式决定默认值；显式额度按已知 DeepSeek 模型的393216（384K）上限校验，兼容服务其他模型交由服务端校验。
- 响应读取容量由2MiB调整为16MiB，避免较大但有效的结果被旧容量限制拒绝。
- 本机用户配置仅将输出额度调整为65536，密钥保持一致；私密配置继续被 Git 忽略。

依据：[DeepSeek Chat Completions 参数](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)、[模型说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，2026-10-25核对。
