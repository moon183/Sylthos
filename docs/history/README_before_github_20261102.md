## 启动原项目

在PyCharm终端或PowerShell运行：

```powershell
cd D:\Kimicode\Gesturerecognition
D:\Anaconda\envs\gesture\python.exe -X utf8 -m src.main
```

解释器使用Python3.11的gesture环境。只执行第二条时，会根据终端当前目录选择项目；不要仍在C盘独立副本里启动。迁移到其他电脑后使用当地Python3.11环境和当地项目目录，不要求创建相同盘符。

## 第一次使用

1. 在设置页选摄像头，点击开始监控，等画面出现。准备好PowerPoint文件并开始放映，或使用配置好路径的一键演示。
2. 张开手掌保持激活，再按手势说明操作。指令配额耗尽时需再次激活；开始监控和激活是不同状态。
3. 默认向右挥下一页、向左挥上一页，方向受配置及镜像影响，请先试一次确认。
4. 握拳→张开进入缩放并缩放一档，✌保持切换缩放方向，食指移动平移，OK退出。激光笔模式内✌循环工具，捏合点击，笔模式握拳书写、食指停笔。
5. 不熟悉动作时先用练习页，准备/结束时收手，识别阶段完成一次动作。老师可自由体验页面，不需要另一个版本。

完整顺序见[DEMO](DEMO.md)。保持时长、配额和阈值以当前配置为准。

## 自定义手势与准确率

样本保存到custom_gestures/，训练使用NumPy MLP与$1模板仲裁。“训练集准确率”含参与训练的数据及生成拒绝样本，不代表新动作识别率。

④验证手势选择已录制类别，在“识别中”做一次动作；次数默认10，可选1—30。结果表给逐次判定与累计正确/有效次数；无手的轮次排除。选择“无关动作”时检查误接收，准确率表示未误接收/有效次数。没有样本/模型时仅有无关动作选项，不代表已能进行有效验证。

验证使用现有状态窗显示摄像头，不开新窗口、不发PPT手势指令、不写训练集。验证自行打开的监控结束时关闭，原来已开的监控保留。报告在evaluations/；清空结果只清显示。当前无参与者身份核验、跨人统计和历史报告选择UI。

彩排统计的指令数表示分发，不表示外部PowerPoint确认成功。历史在logs/rehearsals/；中断报告可查看，累计只纳入完整场次。

## 演讲材料与彩排关联

1. 进入“演讲材料”，点击“导入新材料”选择 `.pptx`。无需打开 PowerPoint，也无需联网。
2. 切换页码核对正文与演讲者备注；表格以文本显示，图片、图表及嵌入对象提示人工补充。隐藏页保留原页码并标记。旧 `.ppt` 需先另存为 `.pptx`。
3. 可填写补充说明或讲稿修正，然后点击“保存材料版本”。提取原文只读；修改补充或名称再保存会创建新版本。“更新当前材料”用于导入同一材料修改后的 PPTX。
4. 填写受众、目标时长和希望强调的内容，点击“保存计划草稿”。这是手工目标草稿，尚未生成逐页重点和时间预算。
5. 在“彩排统计”选择材料版本或计划，再开始彩排。开始后绑定固定；报告与 Markdown 导出保留材料版本和计划编号。需自行确认实际放映文稿与所选版本一致。

材料和计划保存于 `logs/presentations/`，随项目目录迁移；已保存的内容不依赖原 PPTX 路径，旧版本不会被新版本覆盖。旧彩排记录及“不关联材料（仅统计）”继续可用。网络 API 未接入，不会发送 PPT 内容。

## 常见问题

- 没画面：先查设备选择和占用，再在Windows相机应用检查。历史旧摄像头曾在两台电脑都故障，换设备恢复；不要默认是代码或反复改后端。
- 有画面但没动作：看是否激活、是否放映、功能开关和模式，是否处于练习/验证/校准窗口。键盘兜底需要正确的PPT前台。
- 语音没结果：查看输入电平、模型是否就绪、模式及阈值。离线模型首次准备可能需要下载；在线另查凭据及网络，勿在日志公开密钥。
- 更换电脑/目录：检查demo.ppt_path和用户选过的绝对目录。小窗口/高DPI专项仍暂缓，已知范围见C4报告。
- 当前画面不像新版本：先核对工作目录、解释器和Git HEAD；旧exe不会随源码修改自动更新。
